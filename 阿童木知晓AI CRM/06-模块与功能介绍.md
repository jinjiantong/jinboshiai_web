# 阿木木知晓AI CRM · 模块与功能介绍

> 阿木木知晓AI CRM 由 7 大模块组成，覆盖销售全流程：找客户 → 建商机 → 做跟进 → 复盘总结 → 定时自动化 → 自动汇报 → 全局看板。

---

## 模块总览

| 模块 | 一句话定位 |
|---|---|
| 线索管理 | 自动找到对的客户 |
| 商机管理 | 录入即生成全套销售方案 |
| 跟进管理 | 把"记录"升级成"作战" |
| 话术/SOP/复盘 | 让销冠经验可复制 |
| 定时任务 | 到点自动干活，不用盯 |
| 日历与报告 | 自动汇报，不写报告 |
| 老板驾驶舱 | 一眼看懂全局，该找谁该救谁 |

---

## 一、线索管理模块

| 功能 | 说明 |
|---|---|
| 线索获取 | 读取你的产品，自动判断目标行业/渠道，联网调研生成客户线索（含联系方式、来源、评分、推荐话术） |
| 线索转商机 | 一键把线索转为商机，自动联动写入商机表 + 客户表 |
| 线索跟进报告 | 生成「意向判断卡」（需求/预算/决策权/时间）+ 触达方案 + 开场话术 |
| 单条线索快查 | 任意一条线索，一句话即可调出其来源、评分、联系人与推荐动作 |
| 线索池管理 | 统一沉淀全部线索，按来源/评分/状态自动归类，避免线索散落丢失 |
| 线索分配 | 支持将线索分配给指定销售或团队，接单即跟进、进度留痕 |

---

## 二、商机管理模块

| 功能 | 说明 |
|---|---|
| 商机录入 | 自动完成三项：客户画像（先联网调研后入库，7 维画像，查不到如实标注）+ 跟进策略 + 成交概率 |
| 客户 360° 画像 | 跨表聚合 9 个维度，全面看清一个客户——AI 不靠猜，先调研再入库 |
| 商机时间线 | 输出历史跟进时间线 + 后续跟进节奏（基于 SOP 阶段），不跳阶段、按证据推进 |
| 销售计划书 | 含「作战指令卡」，置顶商机评级、赢率、本周必确认清单、关键风险，并匹配产品详情 |
| 审核报告 | 自动生成 7 维合规审核报告 |
| 主动赢单 | 商机确认成交后手动标记赢单，进入七章节复盘与成功因子提取流程 |
| 主动丢单 | 商机确认流失后手动标记丢单，进入七章节复盘与失败原因分析流程 |

---

## 三、跟进管理模块

| 功能 | 说明 |
|---|---|
| 自动结构化录入 | 语音/文字说一段话，自动结构化（客户、商机、内容、待办、风险信号） |
| 健康度评估 | 综合互动活跃度 + 决策链完整性 + 需求匹配度，输出红/黄/绿灯 + 挽救建议 |
| 下一步行动 | 按商机当前阶段，推荐下一步该做什么 |
| 话术推荐 | 从 SOP 检索完整话术全文，标清来源 |
| 赢率预测 | 按「阶段赢率基准 × 健康度系数」计算，附置信度 |
| 风险预警 | 自动识别超期未跟进等风险 |
| 跟进策略报告 | 风险预警清单 + 今日优先跟进 Top10 + 团队执行看板 |
| 跟进留痕可追溯 | 每次跟进自动生成独立跟进报告（13 节固定结构），历史跟进逐条可跳转原报告——全程留痕、谁都能复盘到哪一步 |

---

## 四、话术 / SOP / 复盘模块

| 功能 | 说明 |
|---|---|
| 话术-流程查询 | 精确/语义/场景三级匹配，从 SOP 检索标准话术和流程 |
| 赢单复盘 | 自动生成七章节复盘报告（含成功因子提取） |
| 丢单复盘 | 生成七章节复盘报告（含失败原因 + 改进建议） |
| 复盘防幻觉 | 赢/丢单复盘两段式生成：先聚合真实跟进数据出骨架、再分析成稿——绝不编数据、有据可依 |
| 成功因子沉淀 | 从赢单中提取成功因子，聚合为「成功模式库」 |
| SOP 优化报告 | 基于真实赢单/丢单数据，四维分析 SOP 该补什么、该改什么 |

---

## 五、定时任务管理模块

| 功能 | 说明 |
|---|---|
| 查看任务 | 所有定时任务一目了然：类型、频率、上次/下次运行时间与状态 |
| 创建任务 | 支持每日策略大脑优化（每天 12:00：策略优化 + 赢/丢单因子打标 + 聚合 lift）、定时日报/周报/月报/日程 |
| 修改 / 暂停 / 恢复 | 随时调整频率与内容，不想跑就暂停，想跑就恢复 |
| 删除任务 | 不再需要的任务一键删除，不留垃圾任务 |
| 手动触发一次 | 不等定点，随时手动跑一次，立即拿到最新结果 |

---

## 六、日历与报告模块

| 功能 | 说明 |
|---|---|
| 今日日程同步 | 同步飞书日历 + 关联待跟进商机 |
| 成交冲刺 TOP3 | 按"金额 × 赢率"智能排出今天最该攻的 3 个客户 |
| 日报/周报/月报 | 自动汇总数据生成报告，个人和团队都支持，标题统一「报告类型 - 客户/日期」，可直接归档 |
| 定时报告 | 设置定时，到点自动生成并推送 |

---

## 七、老板驾驶舱模块

| 功能 | 说明 |
|---|---|
| 综合概览 | 核心指标 + 4 周期对比 + 核心发现 TOP3 + 行动建议 TOP3 |
| 团队业绩 | 成交额、赢单、目标达成率、管道覆盖率 |
| 销售漏斗 | 各阶段商机分布 + 转化率 + 瓶颈识别 |
| 风险预警 | 超期未跟进商机，分级标出、定位到责任人 |
| 团队人效 | 人均成交额、人均跟进、排名 |
| 客户资产 | 客户总量、价值分层、集中度、深耕率 |
| 趋势预测 | 下期成交预测（加权管线 + 指数平滑，带置信区间） |
| 员工能力 | 跟进/商机/赢单率，能力亮点 TOP |
| 策略结果 | 生效策略、成功模式、赢单因子快照 |
| 环比比较 | 线索到赢单全流程 14 环节环比 |
| SOP 优化建议 | 阶段健康度、瓶颈、覆盖缺口 |
| AI 大局观 | 销量四杠杆拆解 + 核心判断 + 决策建议 |

---

> 以上 7 大模块相互打通：线索转商机 → 商机做跟进 → 跟进沉淀经验 → 经验反哺新商机，形成"越用越强"的完整闭环。
>
> 注：系统测试已外置为交付前的 QA 验收套件，不属于产品模块；对外不做"系统自测"宣传。
