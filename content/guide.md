## 🧠 主动大脑（系统会在关键时刻主动帮你）

> 除了"你说一句、我做一件"，系统还有一层**主动大脑**：每 2 小时巡检一次你的数据，
> 在**值得提醒你的时候主动告诉你该做什么**。你不用记单词、不用去查，收到提醒照着做就行。

### 它什么时候会主动找我

| 系统主动提醒你         | 它发现了什么          | 你该怎么做                 |
| --------------- | --------------- | --------------------- |
| **承诺快到期 / 已逾期** | 你答应客户某天给的东西快过期了 | 按提示补发/确认，可一键转成待办      |
| **商机失联**        | 好一阵没跟进、可能是流失前兆  | 按提示安排回访，确认客户意向        |
| **商机停滞**        | 一个阶段卡了很久没推进     | 推动下一步，或确认是否遇到竞品       |
| **命中可复用的打法**    | 新商机跟历史赢单很像      | 直接照"复用打法"做（如先出样本比对方案） |
| **命中丢单教训**      | 和上次丢单的坑很像       | 按"规避路径"避开（如先触达最终决策人）  |

### 收到"主动建议"后

- **照着做**：每条建议都带"依据 + 做法"，可直接执行；

- **转成待办**：需要跟进时一键转成行动，有回执才算记上；

- **不需要**：忽略即可，系统会记住你的偏好、慢慢降低同类打扰；

- **能关闭**：不想要主动提醒时可直接关掉，不影响你主动查任何功能。

> ⚠️ 系统**只给你建议、不替你自动执行**——涉及写数据/发外部一定需要你确认。

## 一、5 分钟上手（第一次就用这个）

**不用学任何术语，照这三句说就行。**

**第 1 句 · 记下来**

> "刚跟赛科动力朱总通完电话，聊了试样进度和明年预算，他说下周三前给答复。"

我会：把这次沟通存成记录、关联到客户和商机、列出你要跟进的待办。
你会拿到：一张简短的确认卡 + 这条沟通里提取出的待办。

**第 2 句 · 问今天做什么**

> "今天先跟谁？"

我会：把你自己没做完的事排出来，优先"答应过客户、快到期的"和"卡住的"。
你会拿到：一份按优先级排好的清单，每件事都会说明**为什么排在这个位置**。

**第 3 句 · 要话术**

> "客户嫌价格高，怎么回？"

我会：找到你们公司标准流程里对应的说法，给你一段可以直接用的话。
你会拿到：具体话术 + 出处（如果公司资料里没有，我会直说没有，不编）。

> 这三句就覆盖了日常 80% 的用法。下面是想用更多功能时再看。
>
> 手上有**截图、录音或文档**？都能直接发给我，不用先转成文字（见第四节）。

## 三、每个模块能帮你做什么（共 8 个：7 个业务模块 + 使用说明）

### 1. 线索管理 —— 找客户

*什么时候用：想开发新客户，或手里有条线索不确定值不值得跟。*

| 你想做什么           | 你可以这么说            | 你会拿到                          |
| --------------- | ----------------- | ----------------------------- |
| **找潜在客户** ⭐⭐    | "帮我找几个做固态电池的潜在客户" | 一份线索清单（含公司、来源、评分、推荐理由），确认后入档  |
| **判断一条线索值不值** ⭐ | "XX公司这条线索值不值得跟"   | 需求 / 预算 / 决策权 / 时间四维判断 + 触达建议 |
| **转成商机** ⭐⭐     | "把这条线索转为商机"       | 客户、联系人、商机**自动建好并互相关联**        |

> 注：线索的"领取、分配"目前需要你和主管线下确认，暂不能在对话里操作。

### 2. 商机管理 —— 一个项目从开始到结束

*什么时候用：手上有个具体机会要推进。*

**能接收的资料**：文字、图片、录音、Word/PDF 文档、网址链接——都能直接用，不用先转文字（见第四节）。

| 你想做什么              | 你可以这么说                    | 你会拿到                                                                     |
| ------------------ | ------------------------- | ------------------------------------------------------------------------ |
| **先简单记一下**         | "记个机会：XX公司，想要中试线设备"       | 一条商机记录，只要客户名 + 一句需求就能建；不知道的信息不会瞎填                                        |
| **完整建档备战** ⭐⭐⭐     | "录个商机，详细信息是…"             | 客户画像、商机分析、综合评级、成交可能、**销售计划书**                                            |
| **商机报告（销售计划书）** ⭐⭐ | "帮这个商机生成销售计划书"            | 对**已有商机**出一份**销售计划书**云文档（客户画像＋商机分析＋综合评级＋成交可能＋分阶段执行方案＋SOP 依据），点开即看，不用新建商机 |
| **看客户全貌** ⭐⭐       | "查一下XX客户的画像"              | **客户 360° 画像**：基本情况、联系人、商机、跟进、业务分析                                       |
| **看推进历程** ⭐        | "这个商机推进到哪一步了"             | 商机时间线：历史跟进（每条都能点开）+ 接下来该多快跟一次                                            |
| **检查有没有问题** ⭐      | "审一下这个商机"                 | 审核结果：哪些地方有问题（**会挡住**）、哪些地方建议补                                            |
| **推进阶段** ⭐⭐        | "客户认可方案了，推进到方案沟通"         | 阶段推进（需要你说出"已做了什么 + 客户什么反应"，**避免虚报进度**）                                   |
| **收尾** ⭐           | "这单赢了，600万" / "丢了，客户预算不足" | 统一记录结果与日期；丢单原因会归类留档                                                      |

### 3. 跟进管理 —— 日常最高频

*什么时候用：每次和客户产生联系之后。*

**能接收的资料**：文字、微信/飞书聊天记录、会议纪要、邮件正文，以及**图片、录音、Word/PDF 文档**——都能直接发，不用先转文字（见第四节）。

| 你想做什么             | 你可以这么说            | 你会拿到                                  |
| ----------------- | ----------------- | ------------------------------------- |
| **记录一次沟通** ⭐⭐⭐    | "记录一下刚才的沟通：…"     | 结构化记录（摘要、要点、下一步、待办、风险）+ 需要时再出**完整报告** |
| **看这个单子健康度** ⭐    | "这个商机现在什么情况"      | 健康度评分 + 状态灯 + 成交可能参考 + 数据够不够的说明       |
| **要下一步动作和话术** ⭐⭐⭐ | "客户说价格太高怎么回"      | 具体动作 + **可直接用的话术** + 公司资料出处           |
| **提醒自己别忘事** ⭐⭐    | "我答应客户周五前给方案，提醒我" | 一条可追踪的待办，可以标完成 / 延期 / 取消              |
| **看团队跟进重点** ⭐     | "生成跟进策略报告"        | 风险预警、优先跟进 Top10、团队看板、待办汇总             |

### 4. 话术/SOP/复盘 —— 把经验留下来

*什么时候用：要标准说法时，或一单结束要总结时。*

| 你想做什么         | 你可以这么说       | 你会拿到                                |

## 七、常见问题

**Q：我必须按格式说话吗？**
不用。用大白话说就行，我会自己理解并关联到对应客户和商机。

**Q：可以直接发截图、录音或文档吗？**
都可以。截图、录音、Word/PDF、网页链接都是**直接发给我即可**，不用自己先转成文字。

**Q：一次发一堆资料（好几个客户）怎么办？**
分开说最稳；如果混在一起，我会问你哪段对应哪个客户，不会自己猜。

**Q：它会不会乱改我的数据？**
写入前会告诉你准备改什么；重要信息（金额、归属、对外发送）会明确要你确认。所有变更都留痕。

**Q：同名客户、一个客户多个项目怎么办？**
我会问你必要的那一个问题，不会自己猜。

**Q：记录的时候我不知道预算、也不知道客户到底怎么想，能记吗？**
能。缺的信息我会标成"待核实"，不会编一个填进去。

**Q：它会不会把我的客户信息拿去乱用？**
不会。数据存在你自己的表格里，我只按你的指令读写。

**Q：报告太长不想看？**
日常沟通默认只给你简短确认卡，需要完整报告时你再要。

**Q：怎么知道有没有新版本？**
直接问我「**有新版本吗**」。我会去查最新版本，把**版本号、更新内容、下载链接**一并给你；已经是最新版就告诉你不用动。

**Q：授权到期了怎么办？**
问我「**我的授权还有多久**」，我会给你到期日和剩余天数。快到期或已过期时，按第九节的方式联系我们办理续费即可。

设置完成后，系统会检查一遍数据是否齐全，并告诉你哪些功能可用、哪些暂时不可用；同时顺带查一次是否有新版本。之后销售同事直接打开就能用，不需要再配置。

> **这三样都找卖家要**（联系方式见第九节）：**① 激活码**（必须，没它用不了）、**② 多维表格模板**（标准数据底座，免去自己建表）、**③ SOP 模板**（解锁话术/计划书/复盘评分卡，强烈建议提供）。SOP 决定系统「会不会卖」，而不只是「记不记得住」。

> 没提供资料地址也能用，只是查话术时会提示"公司资料里没有"，不会编造内容。

### 谁能看到谁的客户（可见范围）

**先说清楚**：本技能**自己不设权限**——销售能不能看到别人的客户，取决于**飞书表格的权限设置**和**大家是怎么安装使用的**。分两步做。

**第一步：确认你们属于哪种用法**

| 用法                         | 权限能不能分到人                             |
| -------------------------- | ------------------------------------ |
| **每个人自己装，各用自己的飞书账号**       | ✅ **能**。每人只看到自己有权限的数据                |
| **全公司共用一份安装**（安装时用了一个人的账号） | ❌ **不能**。所有人看到的范围都等于**安装时那个账号**的可见范围 |

> 5 人以内的小团队，共用一份通常就够用——本来大家就互相看得见，配合更顺。人数上去、或开始在意客户归属，建议改成"每人自己装"。

**第二步：在飞书表格里设可见范围**（仅"每人自己装"时需要）

用飞书多维表格的**高级权限**，按下面这张表给每张表设"只能看自己的记录"：

| 表格    | 按这个字段限制                                 |
| ----- | --------------------------------------- |
| 客户信息  | 销售负责人                                   |
| 商机管理  | 销售负责人                                   |
| 线索管理  | 销售负责人                                   |
| 跟进记录  | **跟进人**（这张表字段名不一样，**别配错**）              |
| 销售订单  | 销售负责人                                   |
| 客户联系人 | ⚠️ 这张表**没有**"负责人"字段，只能跟随客户表，建议**不单独限制** |

主管／老板另加进"可见全部"的角色组即可。

**留一个口子**：别让销售**完全**看不到别人的客户——否则他没法判断某家公司是不是已被同事建档，会出现两个人同时跟一家。建议保留"能查重、但看不到详情"。

**设完请用另一个销售的账号自检三件事**：

1. 能看到自己的客户 ✅
2. 看不到别人的客户 ✅
3. 打开老板看板时，**不会**出现全公司明细 ✅

> 技能没有在代码里做"按人过滤"，是为了**不给你虚假的安全感**。真正的隔离请交给飞书表格权限；两边表现不一致时，以飞书为准。
